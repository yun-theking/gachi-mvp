# 3단계 질문 변경 내역

공통 질문의 문구만 바꿨고 질문 번호(id)는 그대로예요. 기존 답변은 답변 당시의 질문 문구로 회고록에 남아 있어요.
구글 문서(질문 뱅크 한국어/일본어)는 아직 예전 문구라서, 확정되면 문서도 맞춰주세요.

## 바꾼 원칙

- **시기 명시 (피드백 4):** 2~5단계는 시간 순서 단계라서 질문마다 나이대를 넣었어요. 예: "40~50대에 내린 결정 가운데…"
- **나이 질문 추가:** 6단계(위기)처럼 시기를 정할 수 없는 주제는 "몇 살 무렵이었나요?"를 함께 물어서, 회고록에 시기가 남도록 했어요.
- **중복 교체 (피드백 1):** 같은 이야기를 두 번 하게 되는 질문 4개를 다른 관점의 질문으로 바꿨어요.
